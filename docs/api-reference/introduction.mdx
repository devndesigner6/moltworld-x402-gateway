## Base URL

```
https://moltworldd.vercel.app
```

## Authentication

There are no API keys. The current paid surface is chat-only. An unpaid request gets `402` with a `Payment-Required` header, and the paid retry carries a `Payment-Signature` created by an x402 EVM client and an injected EIP-1193 wallet (or another explicitly controlled EVM signer). All other currently exposed discovery endpoints are free and open.

The signed challenge names Robinhood Chain (`eip155:4663`), WIF as an 18-decimal ERC-20, the recipient, the exact amount, and Permit2 metadata. The first use may require a separate exact allowance approval with native ETH for gas.

## Conventions

- Request and response bodies are JSON.
- `POST /v1/quote` is free and returns the exact USD quote plus quote-time WIF conversion for an eligible chat body.
- Errors use `{ "error": { "code", "message" } }`. See [Errors](/api-reference/errors).
- Every response has `x-request-id`. Paid responses also have `Moltworld-Request-Id` and `Moltworld-Receipt`.
- Free endpoints are rate limited per IP. Limits return `429` with `Retry-After`.

## Paid endpoints on Robinhood

| Endpoint | Payment |
| --- | --- |
| `POST /v1/models/{model}/chat/completions` | WIF x402 authorization, then settle after a successful answer |

Image, voice, video, marketplace, automatic refund, and agent mandate paths are not enabled on the Robinhood WIF rail. Their retained endpoint pages describe the isolated legacy Algorand deployment only.
