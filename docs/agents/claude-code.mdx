Connect Claude Code to Moltworld's hosted MCP server to discover available chat models and request WIF quotes. The server is keyless and does not sign payments.

## Add the MCP server

```bash
claude mcp add --transport http moltworld https://moltworldd.vercel.app/mcp
```

Run `/mcp` inside Claude Code to check that the server is connected.

<Warning>
MCP connectivity does not grant an agent a wallet. A paid chat call requires a valid caller-generated x402 `Payment-Signature`; the remote server cannot create it. Do not put a seed phrase or master private key in Claude Code configuration.
</Warning>

## Try it

Ask Claude Code to list the live chat models or request a free quote for a chat request. For paid calls, use a caller-side x402 EVM signer and review the exact WIF terms before signing. See [MCP and agents](/agents/mcp) for the supported tool contract.

The WIF deployment currently supports chat only. Autonomous mandates, media generation, and creator payouts are not enabled.
