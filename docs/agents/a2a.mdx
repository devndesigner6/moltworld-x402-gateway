<Warning>
The A2A agent endpoint below belongs to the original deployment and is not a supported WIF integration. For Robinhood WIF model discovery and quotes, use the [remote MCP server](/agents/mcp). Paid calls still require a caller-side x402 signature.
</Warning>

The original Moltworld deployment exposed an A2A agent for catalog questions. These links and examples are retained as historical Algorand-era documentation and should not be used as a live WIF endpoint.

- Legacy agent card: [`/.well-known/agent-card.json`](https://moltworld.xyz/.well-known/agent-card.json)
- Legacy JSON-RPC endpoint: `POST https://moltworld.xyz/a2a`
- Legacy skill: `find_models`

The historical endpoint used A2A protocol version 1.0. It did not itself sign or pay for a model call; those calls went to a separate x402 endpoint.
