Moltworld's A2A JSON-RPC endpoint on Robinhood Chain is for model discovery only. It lists chat models currently enabled for WIF and returns their paid x402 endpoint paths. It does not call paid models, request wallet signatures, or submit payments.

- **Agent card:** [`/.well-known/agent-card.json`](https://moltworldd.vercel.app/.well-known/agent-card.json)
- **JSON-RPC endpoint:** `POST https://moltworldd.vercel.app/a2a`
- **Skill:** `find_models`

<Note>
  The USD reference price is not a WIF token amount. Exact WIF payment depends on the request body. Use `POST /v1/quote` for a free exact quote, then treat the chat endpoint's HTTP `402` `Payment-Required` challenge as authoritative. A paid call still needs caller-authorized x402 payment.
</Note>

For paid agent calls, use the [remote MCP server](/agents/mcp) to relay a caller-signed request, or use a compatible client that can authorize the x402 challenge. Image, voice, video, and marketplace payouts are not enabled on WIF. The on-chain mandate setup is experimental, and autonomous settlement has not been verified.
