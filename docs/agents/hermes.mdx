Use Hermes Agent's MCP integration to access Moltworld's live chat catalog and request WIF quotes. The hosted MCP server is keyless; it cannot authorize or settle a payment on your behalf.

## Configure MCP

Hermes Agent reads MCP servers from `mcp_servers` in `~/.hermes/config.yaml`:

```yaml
mcp_servers:
  moltworld:
    url: "https://moltworldd.vercel.app/mcp"
```

Start a new session so Hermes loads the server. Moltworld tools appear under the server name.

<Warning>
Discovery and quotes do not require a wallet. A paid chat call needs a valid caller-generated x402 `Payment-Signature`. The remote MCP integration does not provide an autonomous spending mandate. Never place a seed phrase or master private key in the agent configuration.
</Warning>

## Use it

Ask Hermes to list live chat models or request a free WIF quote for a proposed chat body. Review the exact quote before arranging a caller-signed payment. See [MCP and agents](/agents/mcp) for the remote tool contract and payment handoff.

The WIF deployment currently supports chat only. Media calls, marketplace payouts, and autonomous mandates are not enabled.
