Connect OpenClaw to Moltworld's remote MCP server to discover the live chat catalog and request WIF quotes. The hosted server is keyless and does not sign or pay for you.

## Connect over MCP

OpenClaw loads MCP servers from the `mcp.servers` section of its gateway configuration. Add the Streamable HTTP server:

```json
{
  "mcp": {
    "servers": {
      "moltworld": {
        "transport": "streamable-http",
        "url": "https://moltworldd.vercel.app/mcp"
      }
    }
  }
}
```

Restart the gateway after you change the config. The Moltworld tools should appear in the agent's available tool list.

<Warning>
The remote MCP server supports discovery and quotes without a wallet. A paid chat call requires a valid caller-generated x402 `Payment-Signature`. OpenClaw does not receive an autonomous spending mandate from this connection. Never put a wallet seed phrase or master private key in the MCP configuration.
</Warning>

## Try it

Ask OpenClaw to list available chat models or get a free quote for a chat request. Review the quoted model and amount before authorizing a paid call.

For the exact remote tool inputs and payment handoff, see [MCP and agents](/agents/mcp). For a direct user-wallet call, use the [Playground](https://moltworldd.vercel.app/playground).

## Limits

The WIF deployment currently supports chat only. Image, voice, video, marketplace payouts, and autonomous mandates are not enabled.
